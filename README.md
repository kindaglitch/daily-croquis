# Daily Croquis v5

毎日6ポーズを無理なく続けるための、端末保存型クロッキー練習アプリです。

## v5の主な機能

- Wikimediaなど外部画像APIに依存しない72種類のカラーSVGポーズ
- 完了後に動きの線・胸郭・骨盤・重心線を表示
- 3秒準備、正確な時刻差計算、一時停止・再開・スキップ対応の集中セッション
- 1体から数えるストリーク、42日ヒートマップ、週間統計、採点推移
- 振り返りと採点の自動保存
- 端末内だけに保存するマイ参考画像
- 履歴と端末画像を含むJSONバックアップ／統合読み込み
- オフライン動作と更新通知に対応したPWA
- 旧`dailyCroquisV2`データの自動移行

## プライバシー

描いた絵、振り返り、採点、追加した参考画像は外部へ送信しません。標準ポーズとアプリコードだけがGitHub Pagesで公開されます。

## 開発

```bash
npm test
```

アプリ本体は依存ライブラリなしのHTML/CSS/JavaScriptです。テストにもNode.js標準のテストランナーだけを使います。
